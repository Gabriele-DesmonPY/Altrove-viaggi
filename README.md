# Altrove Viaggi · demo

Sito demo di un'agenzia di viaggi. Art direction OFFGRID, codice Flowcraft.
Contenuti, prezzi e date sono dimostrativi.

## Avvio

```bash
npm install
npm run dev      # sviluppo su http://localhost:5173
npm run build    # build in dist/
```

Stack: Vite + React + TypeScript, Tailwind CSS v4, framer-motion, lucide-react.
